# RimWorld English

A mobile-friendly 100-word English flashcard site for RimWorld.

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Upload **all files and folders from this package** to the repository root, including `.github`.
3. In GitHub, open **Settings → Pages → Build and deployment → Source**, choose **GitHub Actions**.

After the first workflow completes, your site will be available at:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

## iPhone

Open the site in Safari → Share → **Add to Home Screen**.

## Android

Open the site in Chrome → menu → **Add to Home screen / Install app**.

Learning progress is stored locally in the browser.
